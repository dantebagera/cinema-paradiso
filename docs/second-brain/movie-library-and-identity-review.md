## Decisions and evidence

| Decision | Rule and reason | Authority or source evidence |
| --- | --- | --- |
| Publish a complete Movie View card | The approved ingestion plan requires a stable video, successful media facts, an accepted identity, the required card metadata, and a ready poster state before new strict-ingestion rows reach Movie View. A complete provider snapshot with no usable poster can intentionally show the no-poster design. File View and Maintenance can show incomplete or unresolved records. | [Final-card contract](../plans/online-library-ingestion-final-card-zero-regression-plan.md#31-final-card-only-contract) · [Architecture evidence](../verification/online-library-ingestion/gate-1-architecture-contract.md) |
| Keep Library browsing steady | Publish through the catalog and notify the browser after the commit. A ready movie belongs where the active query, sort, and page place it. A background update preserves the current view and controls. | [No-flicker contract](../plans/online-library-ingestion-final-card-zero-regression-plan.md#32-no-flicker-frontend-contract) · [Catalog ownership contract](../plans/online-library-ingestion-final-card-zero-regression-plan.md#33-catalog-ownership-contract) |
| Use evidence for automatic matches | Current code evaluates provider IDs and title, year, and other identity evidence. The resolver can leave a candidate unmatched or in review when evidence is insufficient. Maintenance distinguishes files without an accepted identity from accepted identities needing verification. A missing provider response alone does not erase a previously accepted identity. | [Identity decision code](../../services/identity_decision.py) · [Accepted-identity tests](../../tests/test_authoritative_identity.py) · [Maintenance projection](../../services/maintenance_audit.py) |
| Preserve explicit manual choices | A manual TMDB or Plex match records the chosen provider identity as a user decision with a manual lock. Reconciliation preserves that choice and discards a stale automatic result if the user chose a match while the lookup was in flight. A completed-download hint follows the same protection. | [Preserved identity contract](../plans/2026-10-23-movie-library-search-and-retry-performance.md#contracts-affected-and-contract-change-decision) · [Manual match owner](../../app.py) · [Ingestion race and hint tests](../../tests/test_library_ingestion_paths.py) |
| Review a proposed correction explicitly | Identity Review offers evidence and proposals. A shadow audit is read-only. Applying a selected proposal in an apply-enabled review checks the path and current identity revision. An identity-audit correction and a manually selected provider match have different recorded origins. | [Documented review workflow](../../README.md#cleanup) · [Review apply code](../../app.py) · [Audit tests](../../tests/test_identity_audit_api.py) |
| Keep display edits separate | A saved display title or year changes what CP shows for the accepted identity. Choosing a different provider match changes which movie the file represents. Use the display override reset to return to provider display metadata when the provider identity is correct. | [Correction controls](../../src/components/MetadataCorrectionModal.jsx) · [Catalog parity tests](../../tests/test_sql_migration_parity.py) |

## Evidence and boundaries

- **Current source** · SQLite is the Movie catalog authority. Current Movie View queries distinguish accepted legacy rows without a publication marker from rows tracked through strict publication. Use the [Atlas diagnosis](../atlas/movie-library-and-identity-review.md#file-on-disk-missing-or-wrong-in-movie-view) to separate scan, identity, publication, filter, and title problems. [Catalog read rules](../../services/catalog_store.py)
- **Historical verification** · The August final-card check used a named live fixture and restored its test changes. The October Library exit audit records a separate isolated test and its limits. Those are dated results for their stated scenarios. [August fixture verification](../verification/online-library-ingestion/gate-10-final-verification.md) · [October Library exit audit](../verification/movie-search-retry/isolated-regression-recovery/library-exit-audit/README.md)
- **Live behavior unverified** · The documentation pass observed the current source and homepage bundle. Live ingestion and identity correction remain unverified for this pass. [Checkout stamp](../atlas/movie-library-and-identity-review.md)
- **Separate catalog** · Existing TV files use their own root, assignment, and episode-binding workflow. [TV Library and Maintenance decisions](tv-library-and-maintenance.md)
- **Download handoff** · A finished transfer enters the Movie catalog through targeted ingestion and clears its Library-pending flag after the required card publication commits. [Movie Downloads and Import decisions](movie-downloads-and-import.md)
