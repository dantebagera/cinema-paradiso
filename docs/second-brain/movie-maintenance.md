## Current source differences to keep visible

- The July ownership note describes a 2% framing tolerance, primary audio only and protected audio trade-offs. The 13 November source uses a 3% framing tolerance, reads audio-language tracks, and can recommend the lower-quality file with a primary-audio trade-off warning when the visual advantage reaches 4× pixels and the other comparison gates pass. A unique audio language requires explicit acknowledgement at deletion. Current tests pin these behaviors. The July note alone cannot establish when the later rules were approved. [July rule](../plans/media-file-facts-authoritative-paths.md#duplicate-comparison) · [Current policy](../../services/maintenance_audit.py) · [Current regression cases](../../tests/test_maintenance_audit.py) · [Acknowledgement test](../../tests/test_maintenance_audit_api.py)
- The single-file Library delete UI has no audio-loss acknowledgement step. The shared API can return 409, so the Library shows the failure and the Maintenance preview is where the user can review and acknowledge the affected audio languages.
