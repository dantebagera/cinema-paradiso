## Queue, progress and subtitles

- **Order and membership** · `_player_queue_projection` supplies Movie collection membership through the existing collection owner and `collection_queue` sorts by release date with one row per movie. It retains the current file version and missing members. A local-only collection fallback blocks autoplay when full membership could not be fetched. `TVPlayback.queue` orders season and episode, keeps unavailable rows with reasons, and gives Specials their own sequence. `PlayerQueue.snapshot` bounds the payload and returns a single-file queue with a visible error when a valid sequence cannot be built. [App wiring](../../app.py) · [Queue](../../services/player_queue.py) · [TV sequence](../../services/tv_playback.py)
- **Switching files** · `PlayerManager._select_queue_item` checks session, media generation, membership and current availability. Automatic selection requires actual EOF and the immediate next item. An unavailable next row, incomplete collection or shared episode file without segments stops automatic progression. A successful switch flushes outgoing progress and sends a new load to the same helper. `CpPlaylistContent` groups TV seasons while retaining original indexes. `CpMenuPopup` and the window chrome handle outside-click dismissal. [Switching and guards](../../services/player_manager.py) · [Playlist](../../native/player/qml/CpPlaylistContent.qml) · [Popup](../../native/player/qml/CpMenuPopup.qml) · [Window chrome](../../native/player/src/WindowsWindowChrome.cpp)
- **Resume and watched** · Movie progress and track preferences live in `playback_history` keyed by catalog path. `PlaybackHistoryService` checks resume settings, minimum position, duration and completion threshold, and uses a session revision to reject stale writes. When enabled, completion uses Movie curation's watched list. Movie Continue Watching groups entries by movie, plays the saved path, and clears only that path's history through `/api/player/progress/clear`. `TypedPlaybackHistory` routes TV to episode `playback_progress` in `tv-catalog.sqlite`. Switching file versions resets that episode's position. Shared files without episode segments do not automatically complete episodes. TV Continue Watching uses the series' current primary action. Removing it hides TV progress through `hide-progress`. [Movie history](../../services/playback_history.py) · [Movie curation](../../services/curation_store.py) · [TV history](../../services/tv_playback.py) · [TV read model](../../services/tv_read_model.py) · [TV repository](../../services/tv_catalog_repository.py) · [Home callers](../../src/App.jsx)
- **Subtitles** · Native track selection and subtitle search use the current player session. `PlayerManager` dispatches search, download and save over the player protocol and rejects late results for a different media generation. `SubtitleService` searches enabled OpenSubtitles and SubDL providers and ranks results using media identity and language preferences. Results are bound to the session and file, expire, and pass archive, format and size checks before storage. Download uses the configured cache or beside-file mode. Saving an already cached subtitle beside the file uses a separate validated native action. [Native bridge](../../native/player/src/PlayerBridge.cpp) · [Session handling](../../services/player_manager.py) · [Provider and storage owner](../../services/subtitle_service.py)

## Browser streaming and IPTV

- **Provider choice** · Settings → **Streaming Link** saves through `GET/POST /api/streaming/config`. `services/streaming_templates.py` owns StreamIMDB, VSEmbed, validation and TV template derivation. `app.py::streaming_config` validates before writing the enabled flag, label and movie/TV templates to application config. It derives the provider name from the saved pair. An explicit TV template takes precedence. Recognized movie presets can derive a TV template when the TV override is empty. Custom movie hosts need their own TV template. [Settings](../../src/features/settings/SettingsWorkspace.jsx) · [API](../../app.py) · [Template owner](../../services/streaming_templates.py)
- **Movie or episode Stream** · Movie opens the source chooser; TV retains its saved-provider direct iframe URL. The extracted [StreamPlayerModal](../../src/components/StreamPlayerModal.jsx) owns both modes. The iframe overlay reports page loading, adds a slow hint at 12 seconds, and hides on load or after 30 seconds. External playback readiness remains unknown. Web streaming does not update owned progress or watched state. See the candidate section above for current selection and cleanup owners.
- **IPTV** · `IPTVWorkspace` and the Movie chooser start and stop provider sessions through the shared `useIPTVPlaybackSession` owner and the IPTV API. `IPTVService.start_playback` issues a local session token and HLS manifest URL. `IPTVPlayer` renders video via HLS and reports non-live progress through the provider history endpoint. Inspect that session and provider state for IPTV issues. Local file launch and the Movie/TV external iframe have their own owners. [Workspace](../../src/features/iptv/IPTVWorkspace.jsx) · [Player](../../src/features/iptv/IPTVPlayer.jsx) · [Routes](../../services/iptv_routes.py) · [Session service](../../services/iptv_service.py)
