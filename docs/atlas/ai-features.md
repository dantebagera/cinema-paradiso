## Provider, job, and account ownership

- `app.py::_ai_provider_service` composes `AIProviderService`. `update_config` compares the expected generation before saving, and `snapshot` pins feature, provider, account, model, configuration generation, and skill for work. `_ai_feature_dependency` checks the appropriate TMDB, Plex, or IPTV dependency. `_ai_check_permission` and `check_evidence_scopes` recheck applicable evidence consent before requests. The ordinary app and IPTV metadata integration settings have distinct owners. [App wiring](../../app.py) · [Provider](../../services/ai_provider.py) · [IPTV settings](../../services/iptv_metadata_settings.py)
- `_get_chatgpt_auth` opens `ChatGPTAuth` and `CredentialStore` under the selected data root at `ai/chatgpt`. The auth owner manages the loopback consent callback, PKCE and state verification, account permission, and refresh. The Windows credential store protects account tokens. `_get_chatgpt_transport` binds the public Responses transport to that account and the job's inference reservation and request slot. The job store sees public account identities and receipts. [App wiring](../../app.py) · [Auth](../../services/chatgpt_auth.py) · [Credentials](../../services/chatgpt_credentials.py) · [Transport](../../services/chatgpt_transport.py)
- `AIJobStore` keeps durable jobs, sessions, result pages, events, action receipts, and inference leases in `ai/ai.sqlite` under the selected data root. `app.py::_get_ai_job_service` binds F1 through F5 to workers. `useAIJob` remembers and restores browser-side references and calls `GET /api/ai/jobs/<job_id>` for status. Cancel, Pause, and Continue are explicit POSTs. Cancellation can bind to the run number so a late request cannot cancel a later run. Account disconnect and data-root changes go through the app's lifecycle wiring. [Store and workers](../../services/ai_jobs.py) · [App wiring](../../app.py) · [Routes](../../services/ai_routes.py) · [Desktop job hook](../../src/features/ai/useAIJob.js)

## From model output to desktop result

**Pick My Movie.** `Recommender.run` loads F1 through `chatgpt_skills.load`, fixes query scope, and requests title/year candidates. `CandidateBatch` can start bounded TMDB reads during streaming. Terminal response validation, fixed scope checks, accepted identity, and deduplication gate publication. The resolver `app.py::_ai_resolve_recommendation` uses CP's Movie matching and enrichment owners. `useAIJob` pages saved cards and `pickStatus` reflects job state. Budget pauses retain existing cards and the exact target. Failed candidates can trigger bounded replacements. Exhaustive factual requests can hand the original prompt to AI Control. In this checkout, `parse_result` enforces the initial or continuation schema locally. The request carries no strict response schema and allows one generic format repair per batch. [F1 worker](../../services/chatgpt_recommendations.py) · [Streaming lookup](../../services/chatgpt_recommendation_stream.py) · [Skill schemas](../../services/chatgpt_skills.py) · [Resolver](../../app.py) · [Status](../../src/features/ai/pickStatus.js)

**AI Control.** `ChatGPTAgent.run` uses the typed `ChatGPTTools` registry for read and prepare actions. `DomainTools` builds proposals using real catalog identities and existing Movie, TV, and IPTV workflows. `ai_control_confirm` checks account and permission before `DomainTools.confirm` checks the revision and selected keys, applies any required phrase or fresh review, and dispatches native owners through `app.py::_ai_domain_dispatch` or the existing Movie action service. Receipts describe what the owner actually completed. TV Follow previews before saving and starting the draft. IPTV classification followed by matching requires a confirmed classification and an explicit next preparation step. [Tools](../../services/chatgpt_tools.py) · [Domain tools](../../services/chatgpt_domain_tools.py) · [Confirmation routes](../../services/ai_routes.py) · [Dispatcher](../../app.py) · [TV task path](tv-follow.md#separate-paths-and-shared-callers)

**Smart Match.** The native coordinator owns the preview for Classic, Ollama, and ChatGPT. ChatGPT's `NativeMatchJob` links the durable job to the native preview. `app.py::_process_selected_smart_match_batch` checks the binding and calls `MovieIdentity.identify` for title hints. CP still queries and ranks TMDB or Plex candidates. The Classic path can continue with a visible AI warning for supported failures. Native preview state is persisted through `AppMetadataStore.get_smart_match_state` and `save_smart_match_state`. `smart_match_apply` checks the saved identity revision for each selected proposal before accepting TMDB or saving a Plex choice locally. [Native wiring and Apply](../../app.py) · [ChatGPT adapter](../../services/chatgpt_matching.py) · [Ranking and state](../../services/smart_match.py) · [Movie identity owners](movie-library-and-identity-review.md)
